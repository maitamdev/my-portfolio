# Mai Tam (MaiTamDev) - Developer Portfolio

My professional developer portfolio built using Next.js, Tailwind CSS, and Framer Motion.

## Features
- **Modern Theme Toggle**: High-fidelity dark/light mode switcher.
- **Immersive Animations**: Smooth page transitions and custom route transition effects using Framer Motion.
- **Floating Skills Cloud**: Interactive skills cloud with orbital animations.
- **Clean Projects Showcase**: Full details on key projects with Github repositories and live links.
- **Comprehensive Education & Experience Timeline**: Displays past roles (Diab, Valley Campus, etc.) and university degree paths.

## Main Projects
- **Anti-Scam Platform**: Security scanner platform designed to detect and report scams.
- **9router**: Universal AI gateway routing API proxy.
- **DHV Guiding Light Web App**: Education tech learning platform with 1-on-1 mentor support.
- **SCS GO EV Optimizer**: EV charging station location optimizer.
- **AIoT E-Learning Platform**: E-Learning portal for IoT & AI integration.
- **Build ChatGPT From Scratch**: Custom neural network chatbot from scratch.

## Tech Stack
- **Framework**: Next.js (React)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Custom SVG

## Run Locally

```bash
npm install
npm run dev
```
